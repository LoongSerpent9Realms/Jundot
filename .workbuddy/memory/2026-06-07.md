## Fix: 界面完全崩溃（控件丢失）

### 问题
用户截图：只显示"构""版"几个文字碎片和 150×100 的小方块，所有内容都挤在左上角。

### 根因
`InitializeComponent()` 里所有关键控件都缺少 `Dock` 属性：
- `_splitMain`：没有 `Dock`，只有默认 `Size(150,100)`
- `_navBar`：没有 `Dock`，没有高度
- `navSeparator`：没有 `Dock`，没有高度
- `_contentPanel`：没有 `Dock`
- `bottomLayout`：没有 `Dock`
- 内部按钮全重叠在 (0,0)

这些 Dock 在 VS 设计器生成时原本由 TabControl 的 `Dock=Fill` 继承，但改成手动 `Panel` + `FlowLayoutPanel` 后没有补上。

### 修复
1. `_splitMain`：`Dock=Fill`, `Orientation=Horizontal`, `FixedPanel=Panel2`, `SplitterDistance=480`
2. `_navBar`：`Dock=Top`, `Height=50`, `FlowDirection=LeftToRight`, `WrapContents=false`
3. `navSeparator`：`Dock=Top`, `Height=2`, `BackColor=#DCDCDC`
4. `_contentPanel`：`Dock=Fill`
5. `bottomLayout`：`Dock=Fill`, `ColumnCount=1`, `ColumnStyle=Percent 100%`
6. `_rtbConsole` / `_bottomBar`：`Dock=Fill`
7. 底部按钮重新排布位置防止重叠

### 构建状态
- `dotnet build` 成功，0 错误 0 警告

## Fix: 页面内容被截断 + 底部栏几乎不可见

### 问题
用户截图：
1. 构建设置页顶部 4 行（Target/Platform/Arch/Jobs）完全消失，"脚本语言"成了第一行
2. 中间有大片空白
3. 底部 Build/Cancel/Progress 按钮缩成白色小条

### 根因
1. **BuildSettingsPage 的 TableLayoutPanel** 使用 `AutoSize = true, AutoSizeMode = GrowAndShrink` —— 内容过多时会**收缩**以适应父容器，而不是显示滚动条，导致顶部行被挤出可视区域
2. **TableLayoutPanel 没有 RowStyles** —— 15 行全部使用默认尺寸策略，行高不可控
3. **bottomLayout 缺少 `RowCount = 2`** —— 行数未显式声明，可能导致底部栏行高计算错误

### 修复
1. `AutoSizeMode.GrowAndShrink` → `GrowOnly`（只增长不收缩）
2. TableLayoutPanel 增加 `Dock = DockStyle.Top`（横向撑满，纵向按内容增长）
3. 显式添加 15 个 `RowStyle(SizeType.AutoSize)`
4. `bottomLayout` 增加 `RowCount = 2`

### 构建状态
- DLL 编译成功；EXE 复制失败（被正在运行的 PackageBuilder PID 20328 锁定）
- 需关闭正在运行的打包器后重新 `dotnet build`

   - 所有 CheckBox/Button/TabPage 文本使用 I18N.T() + Tag
   - BuildsTab 列标题、状态文本（Ready/Missing）、构建计数均使用 I18N.T()
