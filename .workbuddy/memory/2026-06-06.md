## 修改：脚本语言下拉选择 (16:11)

用户要求将 Mono 复选框改成「脚本语言」下拉框，选 C# 时自动启用 Mono 全套后处理。

### 修改内容 (MainForm.cs)
1. **控件声明**: `_chkMono` (CheckBox) → `_cbScriptLang` (ComboBox)
2. **Row 4 布局**: 替换为 "Script Language:" 标签 + 下拉框 (GDScript / C# (Mono))
3. **BtnBuild_Click**: `Mono = _cbScriptLang.SelectedIndex == 1` (选 C# 时启用 Mono)
4. **EnableBuildOptions**: 移除 `_chkMono.Enabled`，添加 `_cbScriptLang.Enabled`
5. **AdvancedTab 说明**: 更新 ".NET SDK" 描述

### 逻辑说明
- 选 **GDScript**: `cfg.Mono = false`，不执行 Mono 后处理
- 选 **C# (Mono)**: `cfg.Mono = true`，BuildEngine 自动执行：
  - `module_mono_enabled=yes`
  - `--generate-mono-glue`
  - `build_assemblies.py`
  - 打包时包含 `GodotSharp/` 目录
